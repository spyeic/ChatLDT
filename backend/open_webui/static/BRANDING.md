# Open WebUI Branding Assets

This directory contains Open WebUI branding assets, including favicons, logos, splash images, app icons, and web app manifest icons.

Open WebUI branding in this directory includes assets, filenames, metadata, manifests, references, and surrounding UI that present or preserve the Open WebUI name, logo, visual, textual, or symbolic identifiers.

Do not alter, remove, obscure, or replace Open WebUI branding except as permitted by `LICENSE`.

See also: https://docs.openwebui.com/license.

## ChatLDT deployment exception (2026-11-16)

The operator explicitly confirmed no more than 50 natural-person end users in any rolling 30-day period, as described in LICENSE condition 4(i). This deployment uses original ChatLDT icons and names under that exception. Prior branding assets have been replaced; the unused upstream welcome media and OpenSearch descriptor have been removed. LICENSE, LICENSE_HISTORY, LICENSE_NOTICE and third-party notices remain unchanged. If that condition ceases to apply, restore required upstream branding or obtain written/enterprise permission before continuing the rebranded deployment.
